Mod Name: The Fallen Spire
Author: RunnerMen
Mod Version: 1.0
Game Version: 7 Days to Die 2.4

DESCRIPTION
The Fallen Spire is the second large-scale Point of Interest (POI) in a trilogy, built entirely with the vanilla editor. It consists of two distinct levels:

Upper Level: A military‑led archaeological excavation site with a camp, command tents, and research equipment.

Lower Level: A cave containing a collapsed ancient chapel, centered around a sarcophagus on a stone pedestal.

The story of the site is told purely through environmental details, lighting, and object placement—no written notes or quests required.

INSTALLATION

Locate your 7 Days to Die game folder.

Navigate to the Data/Prefabs directory.

Copy the .tts files from the mod archive into this folder.

Start a new world or use the in‑game creative menu to place the POI.

Note: If you are using the Compo Pack, this POI is already included.

FEATURES

Size: 100×100

Tier: 5 (designed for experienced players)

Environmental Storytelling: Every detail helps tell the story of the excavation and what lay beneath.

Contrast: Sharp visual and atmospheric shift between the orderly military camp above and the chaotic, sacred cave below.

100% Vanilla: Uses only standard game assets—no custom models, textures, or code.

Compo Pack Ready: Approved and included in the official Compo Pack.

COMPATIBILITY
Compatible with vanilla 7 Days to Die and the Compo Pack. Should not conflict with other mods unless they modify the same prefab names.
